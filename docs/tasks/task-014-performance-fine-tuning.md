# TASK-014 — Melhorias de performance fina

## Objetivo

Revisar performance do portfólio e aplicar melhorias pequenas e seguras.

## Escopo

- Imagens e tamanhos.
- Fontes e carregamento.
- Bundle/client components.
- Rotas estáticas/dinâmicas.
- Cache/revalidate.
- Dados GitHub/Supabase públicos.

## Restrições

- Não trocar stack.
- Não remover funcionalidades.
- Não degradar identidade visual.
- Não criar otimizações complexas sem evidência.

## Critérios de Aceite

- Oportunidades reais de melhoria foram registradas.
- Mudanças aplicadas são pequenas e mensuráveis.
- `npm.cmd run lint` e `npm.cmd run build` passam.
- `docs/handoff.md` registra alterações e riscos.
