# TASK-012 — Configurar domínio final e Search Console

## Objetivo

Planejar e documentar a configuração de domínio final e Search Console.

## Escopo

- Verificar domínio desejado com o usuário.
- Documentar passos Vercel Domains.
- Documentar DNS esperado.
- Documentar Search Console e sitemap.
- Atualizar `NEXT_PUBLIC_SITE_URL` apenas em documentação, salvo confirmação
  explícita para mudança real.

## Restrições

- Não comprar domínio.
- Não alterar DNS.
- Não alterar domínio de produção sem confirmação do usuário.
- Não inventar domínio final.

## Critérios de Aceite

- Checklist claro para domínio e Search Console.
- Pendências dependentes do usuário registradas.
- Nenhum secret ou token exposto.
- `docs/handoff.md` registra decisão e próximos passos.
